Ingestion methods

Two equivalent ways to run the same comparison, depending on where your code lives:

1. CLI CLI

For files already on disk (local testing, batch/cron jobs, CI pipelines):

konkord compare --source examples/panel.hl7 --target examples/panel-bundle-good.json --report out.json

--target accepts a FHIR R4B Bundle/resource JSON file. Exit code 1 on an overall FAIL, 2 on a parse error — convenient for CI gating. Add --save (with the db extra installed) to persist the report as a job.

2. Python library LIB

For callers that already hold the data in memory, or that want to call Konkord from a script or notebook — import the adapters and reconciliation engine directly, no intermediate files required:

from konkord.adapters.hl7v2 import parse_hl7_oru
from konkord.adapters.fhir import load_fhir_bundle
from konkord.reconciliation import compare_many

source = parse_hl7_oru(open("panel.hl7").read())
target = load_fhir_bundle("panel-bundle-good.json")
report = compare_many(source, target)
print(report["overall"])  # PASS | FAIL | WARN | INDETERMINATE

The single-observation path (konkord.engine.parse_hl7_obx, load_observation, compare) and the other domain-specific compare_many_<domain>() functions (medication, allergy, condition, ...) follow the same pattern.
