Overview

This reference documents every supported way to get data into Konkord for source-to-target reconciliation: which file formats are accepted, how to run a comparison (CLI or Python library), and how ingestion failures are reported.

Every Konkord comparison needs exactly two inputs:

  • Source — an HL7v2 message (the system of record emitting the original clinical/administrative event).
  • Target — a FHIR R4 resource or Bundle (the system the data was translated/synced into).

Konkord parses both, runs the relevant rule pack(s) for the detected domain (lab results, medications, allergies, encounters, claims, etc.), and returns a structured report: one PASS / WARN / FAIL / INDETERMINATE finding per field-level check, plus an overall status.
